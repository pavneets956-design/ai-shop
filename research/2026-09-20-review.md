## Implemented improvements

1. **Enquiry positioning:** the redesigned page promised websites/apps but its required goal label still asked “What are you trying to automate?”. The label, hint and empty-goal validation now welcome any build. Layout and white/graphite/blue direction remain intact; no claims, prices or proof were invented.
2. **Stalled lead submissions:** fetch had no timeout, so a connection that never completed left Sending disabled indefinitely. A 30-second AbortController deadline now restores a retryable error with entered information retained. It explicitly says the request may already have arrived; server-side duplicate recognition remains authoritative. Timers are cleared on every outcome. No new data collection or analytics payload was added.
3. **Public JSON boundaries:** `/api/demo`, `/api/tools-demo`, `/api/tools`, `/api/tts` and enabled `/api/consultation` previously parsed an unbounded body and trusted it as an object. A JSON `null` could throw before their error handling; clamping fields afterward did not cap incoming memory. Shared streaming parsing now rejects non-object/malformed JSON with 400 and bodies over 32 KiB with 413, counts UTF-8 bytes, rejects deceptive Content-Length values and cancels oversized streams. Existing field validation, cost limits and consultation/agent kill switches remain in place. This is an input guard, not a claim of distributed rate limiting.
4. **Security dependencies:** prepared Next.js 15.5.25, NextAuth 4.24.15, PDF.js 6.3.289 and compatible transitive updates. Next 15 requires awaiting route parameters; migrated public slug pages, account query parameters and guarded contact handlers accordingly. The unused parameters of the dormant mock lead-detail page were removed. A scoped PostCSS 8.5.28 override replaces Next's vulnerable pinned dependency. Vitest is updated to 4.1.11 to fix the test-server advisories. The prepared lockfile reports zero npm advisories including dev dependencies; this still needs install/build verification.
5. **Local validation documentation:** Playwright instructions now use `npx next build` instead of the migration-running npm build command. AGENTS orientation reflects Next 15.

The system npm 10 peer resolver crashed while resolving the updated test tooling. A temporary npm 11 CLI successfully generated the lockfile in a separate metadata-only folder. No global npm installation or change to the denied dependency folder was made. Use npm 11 for the clean validation install.

The runtime upgrade addresses the installed Next 14 security exposure rather than shipping another cosmetic redesign. Primary reference: [Next.js AVIF image-optimization advisory](https://github.com/vercel/next.js/security/advisories/GHSA-2xp9-vwfh-vxw4), patched in 15.5.24; this branch selects the newer 15.5.25 patch.
